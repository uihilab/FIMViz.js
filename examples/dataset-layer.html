FIMViz — Dataset → Layer scenarios

Exercises the migration primitives on a real map, with no API key: a tiny in-page demo map provider draws overlays as stretched <img>s, so RasterLayer.render() / VectorLayer.render() / setSources() run their actual pipelines. Serve from the repo root (npx serve .), build the bundle first (npm run build). Samples in assets/SampleFiles/.
