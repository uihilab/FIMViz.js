FIMViz — examples

Runnable demos of the fimviz package. Each is a standalone HTML page that imports the built bundle.

Setup: build the library first — npm run build — then serve the repo root (npx serve .) and open this page. Pages import ../dist/fimviz.js via an import map.
keyless pages run as-is (Leaflet / demo provider); Google key pages need a Google Maps JS API key you supply (never committed). Raster samples live in assets/SampleFiles/.

The engine→host busy event seam, from a host with none of FIMViz's widget markup — mount + warp via the core fimviz bundle. Carries decoy copies of the element ids the engine used to write. The depth-layer render/hover/remove demo it used to include needed the removed dev-only bench bundle and is currently disabled.

method-playground.html

Every public method of every module, called once with sample parameters — a runnable scratch bench (no assertions; it just shows each return value). Pure modules (ColorScale/Legend/Stats/Filter/rasterOps/Dataset/Storage/materialize) plus the map-coupled ones (FimMap/RasterLayer/VectorLayer/Comparison/Ensemble/ui) on a real keyless map. Synthetic in-memory data — no uploads. All live objects on window.FIM; edit any call and reload.
