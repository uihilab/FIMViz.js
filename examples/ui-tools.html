FIMViz — UI components

Everything on the left is a fimviz/ui export, mounted the way an app would mount it. Six layers in two overlapping clusters — three coincident rasters plus a vector over Mississippi, two overlapping vectors over Iowa. Click one spot twice to cycle through what is stacked there; use fit in the layer list to travel between clusters. Serve from the repo root; run npm run build after editing src/.
