FIMViz — guided verification

0 pass 0 fail 0 left
What this page is. A manual pass over the things an automated test cannot judge — how it looks and how it feels. Each step says what to do and what you should see; mark it Pass or Fail. Nothing is sent anywhere — “Copy report” puts a Markdown summary on your clipboard.
  1. Build first: npm run build.
  2. Serve the repo root: npx serve . (not the examples/ folder — pages read ../dist and ../assets).
  3. Open /examples/verify.html. Leaflet needs no key; add ?provider=google for the Google pass.
  4. Work top to bottom — later steps reuse the layers earlier ones load.

1 Boot & basemap …

Do Nothing — the map boots on load.

Expect
  • A real, pannable basemap fills the right-hand pane.
  • Dragging and scroll-zoom both work.
  • The browser console has no red errors.

2 Toast connectToast

Do Click each level. The buttons only fim.emit('notify', …) — the engine never calls the toast itself.

Expect
  • A toast appears for each, then dismisses itself.
  • The four levels are visually distinguishable (colour/icon).
  • Rapid clicks stack or replace cleanly — never overlap illegibly.

3 Raster + tools panel idle

Do Load the bundled sample (or pick your own GeoTIFF), then drag the opacity slider and change the palette in the tools panel.

Expect
  • A coloured raster lands on the map and the view fits to it.
  • Opacity changes the overlay live, with no flicker or reload.
  • Changing palette recolours both the raster and the legend ramp.
  • The legend ramp is a real gradient, labelled with min/max.
  • Stats show plausible numbers (min ≤ mean ≤ max, count > 0).

4 Hover tooltip bindHoverValue

Do Move the pointer slowly across the raster, then off its edge onto bare basemap.

Expect
  • A tooltip tracks the cursor showing the pixel value + unit.
  • Values change as you move; they are not frozen on the first reading.
  • Leaving the raster hides the tooltip — it does not linger or stick.

5 Vector polygons idle

Do Load the county boundaries, then click any polygon.

Expect
  • 99 county polygons draw with a visible fill and a distinct outline.
  • Clicking one opens an info window listing that feature's properties.
  • The properties belong to the polygon you actually clicked.

6 Point styling idle

Do Add six inline points, each styled from the same neutral { fillColor, strokeColor, pointRadius } vocabulary the polygons above use.

Expect
  • Six filled circles — not broken-image icons, and not default pins.
  • Colours run left→right through the palette; each has a dark outline.
  • Radii grow left→right (4px → 14px), proving pointRadius is honoured.
  • They look the same on Leaflet and Google — switch providers and re-check.

Leaflet's default point is an L.marker whose icon PNGs are resolved from a leaflet.js script tag. This package bundles Leaflet, so that tag never exists and the default rendered as a broken image that ignored every style key.

7 Multi-layer dispatch idle

Do Stack three translucent overlays, then click where they overlap — first with “top absorbs” off, then on.

Stack, then click the overlays.
Expect
  • Absorb off: the log lists z=2, z=1, z=0 — top-down, all three.
  • Absorb on: only z=2, followed by “ABSORBED — dispatch stops”.
  • “Simultaneous” delivers to all layers regardless of absorption.

8 Region draw → scoped stats idle

Do Click Draw region, click ≥3 points on the raster, then Finish. While drawing, try hovering the raster.

—
Expect
  • The outline draws as you click, and closes into a polygon on Finish.
  • While drawing, the hover tooltip is suppressed — that is the modal capture.
  • Finish prints stats scoped to the region: a smaller count than step 3's.
  • Hover works again afterwards.

9 Operations panel idle

Do Apply Threshold, then Mask to the step-8 region, then Reset.

Expect
  • Threshold visibly changes the raster and the legend/stats refresh to match.
  • Mask clips it to the drawn region; everything outside disappears.
  • Reset restores the original raster exactly.
  • Each op is a lazy Dataset op — the source file is never re-read.

10 Temporal formats separate page

Do Open temporal-netcdf.html and run all three bundled samples (NetCDF4, Zarr, GRIB2).

Expect
  • Each scans, reports its variable/CRS, and puts a first frame on the map.
  • The slider scrubs the time axis; the timestamp advances with it.
  • The legend ramp is a real gradient with numeric bounds.
  • reduce('mean') and reduce('max') collapse the axis to one grid.
  • GRIB2 needs its extent override — it should say so rather than mis-place the data.
